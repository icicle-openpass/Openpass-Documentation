## Overview

### . /

This folder contains all files related to run Openpass Appication. Every component plays an independent role.

```
./                     
├── adminTools                
├── bin              
├── ea1openpass
├── helmbase       
├── icicleEdge       
├── local.softwarepilotservice       
├── httpservice.logs         
└── install.sh         
```

### local.softwarepilotservice

This folder holds all the files which are required to fly the drone. This folder help you to connect the drone with our application.
```
local.softwarepilotservice
├── cgi-bin
│   ├── connect.py       
│   ├── sendBasicCmd.py          
│   └── sendDownloadCmd.py                  
├── firstprogram.py                  
├── icicle.firstfile                  
├── index.html                  
├── logger                  
├── onDevice                  
└── pushreload.sh       
```

This structure give us to maintain the robustness of the application.
